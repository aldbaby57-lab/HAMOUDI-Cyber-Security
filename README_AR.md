# HAMOUDI – Cyber Security

هذا مشروع Flutter أولي لتطبيق HAMOUDI.

## الموجود حالياً
- واجهة عربية أولية بألوان كحلية وزرقاء.
- طلب موافقة قبل فتح منتقي الصور.
- اختيار الصور يدوياً عبر منتقي النظام.
- اختيار صورة واحدة يمكن استخدامها كلقطة شاشة محفوظة مسبقاً.
- عرض أسعار الاشتراك المقترحة: 4.99 دولار شهرياً و39.99 دولار سنوياً.

## غير المنفذ بعد
- لا يوجد خادم خلفي منشور.
- لا يوجد ربط فعلي مع Telegram.
- لا يوجد إرسال للصور.
- لا توجد مشتريات داخل التطبيق أو تحقق من الاشتراكات.
- لا توجد ملفات تثبيت APK أو IPA أو EXE.

## تشغيل المشروع
يتطلب Flutter SDK:
1. `flutter pub get`
2. `flutter run`

لا تضع رموز Telegram أو مفاتيح API أو كلمات مرور داخل التطبيق أو مستودع GitHub.
